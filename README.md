# 牛肉场景创作

`beef-scene-creator` 是一个用于 Codex 的牛肉产品场景创作 Skill。先读取牛肉产品图，再结合场景参考图设计主盘、配菜、整桌餐具、布局与拍摄视角，并逐张接续内置图片生成工具。

## 能做什么

- 尽量保留牛肉的雪花纹理、筋膜、片形与叠放关系，让容器适配牛肉。
- 分开设计牛肉与原盘外观，根据场景选择主盘材质、质感、颜色和盘沿，再协调整桌器物。
- 规划丰富的配菜和有差异的餐具组合，不固定材质配额或轮换套餐。
- 默认生成 10 张：同类空间 5 张、跨空间 5 张；也支持自定数量、比例或只要提示词。
- 每张绑定原始场景图和选用的产品图，交付图片、完整提示词与实际成图核对结果。

## 使用

安装后，提供牛肉产品图与场景参考图，例如：

```text
调用 $beef-scene-creator，根据这些牛肉产品图和场景参考图生成 10 张图片。
尽量保留牛肉纹理与形态，并让各张的牛肉主盘、配菜和整桌搭配自然且有可见差异。
```

也可以要求“只要提示词”“只要同类空间”或指定生成数量。仅讨论、检查或修改 Skill 时不会自动启动生图。

## 安装

在 Codex 中请求：

```text
使用 $skill-installer 从 https://github.com/mumu0214-chou/beef-scene-creator 安装 skills/beef-scene-creator。
```

仓库若为私有，安装环境需要具备该仓库的访问权限。也可将 `skills/beef-scene-creator` 放入 Codex 的本地 Skill 发现目录；支持目录链接，可将实际文件保存在其他磁盘。安装位置与自动发现机制参见 [OpenAI 官方 Skill 文档](https://learn.chatgpt.com/docs/build-skills)。

## 条件与限制

这是指令型 Skill，不附带模型、图片生成额度或 API 密钥。执行生图需要当前环境提供内置图片生成工具，并能读取输入素材；工具不可用时会明确说明并交付提示词。

生成式图像可能改写局部纹理，不能保证原始 RGB 像素或每条脂肪纹路逐点一致。生成完成与核对达标分别报告，餐具多样性按实际成图检查。

本仓库包含 Skill 规则和界面元数据，不包含用户参考照片、生成样图、聊天记录或本机私有配置。该版本由 `style-lock-prompt-trial` 的主盘设计更新版更名而来，与原 `style-lock` 分析型 Skill 独立。
